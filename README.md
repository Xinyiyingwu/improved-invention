《心一映物》

一本关于保持觉知、实事求是的书。

核心命题：宇宙有两大根本面向——心一与物一。心一，是能知能觉能用的本体；物一，是物理世界的客观法则。二者非一非异，是同一个整体运作的两种面相。迷者将此运作割裂为“我”与“世界”，悟者见此运作之全貌，明心一之主，顺物一之行。

本书内容：一套以“心物铁律”为总纲，从觉醒、功夫、践行到终极归位的完整心法体系。附篇对六道轮回、善恶有报等传统命题，以及洗碗、愤怒、色欲等日常困境，给出基于当代语言的实操解读。

本书写给谁：每一个正在诚实的跌倒者。不是寻找完美的修行者，不是提供宗教教条。是陪伴你一次次忘记，又一次次想起。

声明：本书为独立创作的个人思想见解，非学术论著，非医疗手册，不属任何宗教门派。本书内容允许非商业性免费转载与分享，但禁止用于任何商业用途。
